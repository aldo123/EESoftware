A. Lihat daftar semua tabel di database

;
SHOW TABLES;

B. Lihat struktur/kolom tabel

sql
DESCRIBE nama_tabel; -- Misal: DESCRIBE snlist_cp02;

C. Lihat isi data tabel

sql
SELECT * FROM nama_tabel; -- Melihat semua data

2. Cara Membuat Tabel (CREATE TABLE)
Gunakan perintah CREATE TABLE. Pastikan Anda sudah memilih database yang benar sebelumnya.

sql
CREATE TABLE IF NOT EXISTS nama_tabel (
    id INT AUTO_INCREMENT PRIMARY KEY,
    kolom_1 VARCHAR(50) NOT NULL,
    kolom_2 VARCHAR(20),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

A. Hapus tabel secara permanen

sql
DROP TABLE nama_tabel; 
-- atau lebih aman:
DROP TABLE IF EXISTS nama_tabel; 

B. Jika Anda hanya ingin menghapus datanya saja, tapi menyimpan struktur tabelnya

sql
